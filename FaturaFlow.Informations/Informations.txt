1. PROPÓSITO DO PROJETO
O FaturaFlow 2.0 é um sistema completo de faturação e gestão de inventário 
desenvolvido como projeto final para a Prova de Aptidão Profissional (PAP) 
no curso de Técnico de Informática de Gestão (2025-2026).

O objetivo principal foi elevar o padrão de desenvolvimento acadêmico para 
um nível profissional, implementando uma arquitetura escalável, modular 
e resiliente, capaz de lidar com processamentos intensivos em segundo plano.

2. STACK TECNOLÓGICA (BACKEND & INFRAESTRUTURA)
O sistema foi construído sobre as tecnologias mais modernas do ecossistema .NET:

   - Linguagem: C# (.NET 8.0)
   - Arquitetura: Clean Architecture & Domain-Driven Design (DDD)
   - Interface: Razor Pages (Server-side rendering para alta performance)
   - Mensageria: RabbitMQ (Processamento assíncrono de documentos e e-mails)
   - Banco de Dados: MySQL 8.0
   - Contentorização: Docker & Docker Compose
   - Geração de PDF: QuestPDF (Baseado em layouts fluentes)
   - Comunicação: MailKit (Integração SMTP para envio de faturas)

3. ARQUITETURA E DIFERENCIAIS TÉCNICOS
Diferente de sistemas monolíticos convencionais, o FaturaFlow 2.0 utiliza:
   - Worker Services: Um serviço independente que consome filas do RabbitMQ, 
     permitindo que o utilizador continue navegando enquanto faturas 
     pesadas são geradas e enviadas por e-mail (Princípio Fire-and-Forget).
   - Camadas Independentes: Domain, Application, Infrastructure, Presentation 
     e Worker, garantindo que a lógica de negócio seja testável e isolada.
   - Resiliência: Estratégias de Retry em código para garantir a conexão 
     entre os contentores Docker durante o startup.
